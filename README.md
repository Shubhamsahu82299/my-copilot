# My Copilot Agent

An autonomous AI coding and debugging assistant for VS Code powered by Google Gemini.

## Features

- **Autonomous Actions**: Create and modify files directly in your workspace.
- **Side-by-Side Diff Reviews**: Accept or discard code modifications visually.
- **Terminal Execution**: Run suggested build, run, and install commands in the integrated terminal with one click.
- **Dynamic API Key Pool**: Add multiple Gemini keys with priority sorting, manual selection, and auto-rotation on quota exhaustion (429/403).
- **Session History & Token Optimization**: Archive chats, reload past sessions, and configure sliding context window limits.

## Configuration

Open the Copilot sidebar, click the **Settings (Gear icon)** at the top, and add your Gemini API key and model version.
